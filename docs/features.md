# Что есть в тренажёре

## Школа дебютов

Программа — **15 семейных блоков**. Внутри каждого блока промежуточные шаги одной семьи: **база → схемы → фишки/жертвы**. Следующий блок (другая семья) открывается только когда закрыт весь предыдущий.

Урок открывается после сдачи предыдущего: **все** линии «за тебя» и «против тебя» в режиме **Проверка** без ошибок хотя бы раз.

Блоки:

1. **Итальянская** — итальянская → двухконей → жареная печень → Эванс
2. **Шотландская** — четырёх коней → шотландская → шотландский гамбит
3. **Испанская** — база → открытая → Маршалл → Берлин
4. **Острые e4 e5** — венская → русская → королевский гамбит
5. **Системы d4** — лондон → Колле → Йобава
6. **Каро / …d5** — Каро-Канн → Панов → скандинавская
7. **Французская** — база → Винавер → Тарраш
8. **Ферзевый гамбит** — отказ/славянская → принятый → полуславянская
9. **Индийские** — Нимцович → Бого → новоиндийская
10. **Гипермодерн** — КИД → Грюнфельд → Бенони
11. **Сицилианка** — база → Алапин → дракон
12. **Фланги** — английское → Рети → голландская
13. **Современные белые** — Торре → каталон → Тромповский
14. **Гибкий ответ на e4** — Пирц → современная → Алехин
15. **GM-фишки** — английская атака → Ботвинник → Морра

На главной: «Продолжить урок», треки со слайдером карточек, статусы закрыт / открыт / сдан. В тренажёре — слайдер уроков текущего трека.

## Дебюты

База (`openings.ts` + `extraOpenings.ts`) плюс пакеты `gmOpenings.ts` и `familySteps.ts` (промежуточные шаги семей). У каждого дебюта линии «за тебя» и «против тебя».

В каждой схеме несколько линий, около восьми ходов ученика.

## Режимы

- **Учить** — тренер заранее называет ход и причину, ученик делает его на доске
- **Проверка** — тренер даёт идею **без названия хода** и без стрелки на правильный ход; при ошибке ход тоже не называется. Объяснение приходит после верного хода. В школу засчитывается только чистая проверка.
- **Повторение** — проверка линий, у которых вышел срок

Соперник ходит сам. Справа чат: подсказка, ошибка, выбор вариации, «Следующая вариация». Стрелки листают уже сделанные ходы. Кнопка рядом копирует эти ходы в буфер: дебют, сторона, нотация и FEN позиции на доске.

После каждого хода на доске ненадолго появляется зелёная стрелка на центральную пешку или фигуру, которую этот ход прикрывает в дебюте. Задние пешки не подсвечиваются. Наведение на фразу в чате (на телефоне — нажатие) показывает то же самое вместе со стрелкой самого хода. Позиция при этом остаётся прежней.

Когда линия кончается, тренер пишет, какие ходы дальше возможны. Жёлтая стрелка — лучший, синяя — запасной. Нажатие на строку оставляет на доске только этот ход.

## Мои партии (chess.com)

По никам скачиваются публичные PGN в `games/`. Stockfish считает потери в центропешках, скрипт собирает:

- самые частые дебюты и результат по сторонам
- повторяющиеся неточности, ошибки и зевки
- узкие места в дебюте (первые ходы)

В приложении раздел **Мои партии**: вводите ники → онлайн-скачивание и анализ → **план развития** (узкие места, что тренировать, план на неделю) → список ошибок и режим «найди лучший ход». Как поднять API: [games-analysis.md](games-analysis.md).
