# Что есть в тренажёре

## Школа дебютов

Программа — **15 семейных блоков** школы развития + отдельный раздел **Гамбиты**. Внутри школьного блока: **база → схемы → фишки**. Следующий школьный блок открывается только когда закрыт весь предыдущий. Гамбиты открыты сразу и не входят в цепочку школы.

Урок открывается после сдачи предыдущего: **все** линии «за тебя» и «против тебя» в режиме **Проверка** — по **3 чистых прохода подряд** без ошибок (оранжевый → жёлтый → зелёный). Зелёный фиксируется.

Блоки школы:

1. **Итальянская** — итальянская → двухконей → жареная печень
2. **Шотландская** — четырёх коней → шотландская → шотландский гамбит
3. **Испанская** — база → открытая → Маршалл → Берлин
4. **Острые e4 e5** — венская → русская → королевский гамбит
5. **Системы d4** — лондон → Колле → Йобава
6. **Каро / …d5** — Каро-Канн → Панов → скандинавская
7. **Французская** — база → Винавер → Тарраш
8. **Ферзевый и славянская** — отказ → славянская → принятый → полуславянская
9. **Индийские** — Нимцович → Бого → новоиндийская
10. **Гипермодерн** — КИД → Грюнфельд → Бенони
11. **Сицилианка** — база → Алапин → дракон
12. **Фланги** — английское → Рети → голландская
13. **Современные белые** — Торре → каталон → Тромповский
14. **Гибкий ответ на e4** — Пирц → современная → Алехин
15. **GM-фишки** — английская атака → Ботвинник → Морра

**Гамбиты** (вкладка `/gambits`, вне школы): гамбит Эванса (в т.ч. мат с жертвой ферзя).

На главной — только школа развития (у блоков флаги семей). Гамбиты — отдельная вкладка в шапке рядом с «Мои партии» и «Повторение».

## Дебюты

База (`openings.ts` + `extraOpenings.ts`) плюс пакеты `gmOpenings.ts` и `familySteps.ts` (промежуточные шаги семей). У каждого дебюта линии «за тебя» и «против тебя».

В каждой схеме несколько линий (обычно около восьми ходов ученика). Острые тактические линии (жертвы, матовые атаки) доводятся до логического конца — в том числе до мата, если финал учебный (например Эванс: «Мат с жертвой ферзя»).

## Режимы

- **Учить** — тренер заранее называет ход и причину, ученик делает его на доске
- **Проверка** — тренер даёт идею **без названия хода** и без стрелки на правильный ход; при ошибке ход тоже не называется. Объяснение приходит после верного хода. В школу засчитывается только чистая проверка: **3 раза подряд** без ошибок → оранжевый → жёлтый → зелёный. Ошибка до зелёного сбрасывает счётчик; зелёный не откатывается.
- **Повторение** — проверка линий, у которых вышел срок

Соперник ходит сам. Справа чат: подсказка, ошибка, выбор вариации, «Следующая вариация». Стрелки листают уже сделанные ходы. Кнопка рядом копирует эти ходы в буфер: дебют, сторона, нотация и FEN позиции на доске.

После каждого хода на доске ненадолго появляется зелёная стрелка на **свою центральную пешку**, которую этот ход реально прикрывает. Пустые поля атаки не подсвечиваются. Наведение на фразу в чате (на телефоне — нажатие) показывает то же самое вместе со стрелкой самого хода. Позиция при этом остаётся прежней.

Когда линия кончается, тренер пишет, **зачем** следующие ходы: жёлтая стрелка — лучший план (развитие, давление, укрытие короля), синяя — запасной. Нажатие на строку оставляет на доске только этот ход.

## Мои партии (chess.com)

По никам скачиваются публичные PGN в `games/`. Stockfish считает потери в центропешках, скрипт собирает:

- самые частые дебюты и результат по сторонам
- повторяющиеся неточности, ошибки и зевки
- узкие места в дебюте (первые ходы)

В приложении раздел **Мои партии**: вводите ники → онлайн-скачивание и анализ → **план развития** (узкие места, что тренировать, план на неделю) → список ошибок и режим «найди лучший ход». Как поднять API: [games-analysis.md](games-analysis.md).
