# Что есть в тренажёре

## Дебюты

За белых:

- Итальянская партия — спокойный центр, ответ на ...Nf6, удар d4
- Лондонская система — против ...d5, против фианкетто, ферзь на b6

За чёрных:

- Каро-Канн на 1.e4 — 3.Nc3, 3.e5, размен
- На 1.d4 — отказанный ферзевый гамбит (e6), славянская (c6), ответ на лондонскую

В каждой схеме три линии, около восьми ходов ученика.

## Режимы

- **Учить** — тренер заранее называет ход и причину, ученик делает его на доске
- **Проверка** — тренер даёт идею без хода; объяснение приходит после верного хода
- **Повторение** — проверка линий, у которых вышел срок

Соперник ходит сам. Справа чат: подсказка, ошибка, выбор вариации, «Следующая вариация». Стрелки листают уже сделанные ходы.
