# Дебюты

Школа шахматных дебютов: уровни, строгая разблокировка уроков, доска и чат тренера.

За белых — итальянская семья, шотландская, испанская, лондонская, скандинавская. За чёрных — Каро-Канн, французская, ответ на 1.d4.

## Запуск

```bash
cd apps/web
npm install
npm run dev
```

Откройте http://localhost:5173

Проверка, что ходы в линиях легальны:

```bash
cd apps/web
npx tsx scripts/validate-openings.ts
```

## Как учить

- **Учить** — тренер называет ход, ты повторяешь на доске
- **Проверка** — ход нужно вспомнить самому
- Ошибка возвращает линию на завтра. Чистый проход уходит на 1, 3, 7, 16 и 35 дней

## Партии с chess.com

На странице **Мои партии** введите ники и нажмите «Скачать и разобрать» (нужен запущенный API).
